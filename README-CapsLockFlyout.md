# CapsLockFlyout 1.1.0 使用说明

为 Windows 11 提供输入法、大写锁定和 G-Helper 状态浮窗。音量与屏幕亮度继续由系统自身显示。

## 输入法提示

| 输入法 | 模式 |
| --- | --- |
| 汉语 | 中文模式、英语模式 |
| 英语 | 直接输入 |
| 日语 | 平假名、片假名、直接输入 |

程序每 120 ms 在后台查询前台应用的实际状态，不以输入按键预测结果，也不修改输入法。
输入法浮窗宽度固定，中间显示语言，右侧模式名在固定区域居中；语言与模式变化分别过渡。

启动或会话恢复后先静默建立基线，有变化才显示。状态不变的 Shift 不会弹出额外提示。
日语输入法下抑制大写锁定提示，避免模式切换快捷键误触发。

Win+Space 面板的高亮项不一定已经生效，本程序等实际状态提交后更新，不跟随未提交的选中项预测。
日语全角与半角片假名共用“片假名”名称。
部分输入法或应用可能返回未知或滞后状态，当前验证不覆盖所有第三方组合。

## 其他功能与外观

- 大写锁定、Fn 锁定、麦克风、触控板等二分态动画。
- G-Helper 性能模式、GPU 模式、键盘背光与灯效、刷新率、屏幕色彩等硬件状态；可用项目取决于设备支持。
- Windows 11 风格的 48 DIP 高度、圆角、亚克力背景、DWM 描边与阴影，自动跟随浅色/深色主题。
- 整个窗口滑入滑出，可见期间按 120 Hz 目标频率更新位置；实际流畅度受屏幕与系统负载影响。
- 每次显示及动画中读取任务栏边界，适配自动隐藏任务栏。
- 键盘灯效与输入法保持各自固定宽度；其余浮窗按内容调整。

输入法状态使用查询方式；原有 G-Helper 常用快捷键仍采用即时预测后校准，两者独立。
输入法与大写锁定无需安装 G-Helper 或 Windhawk。

## 安装与升级

运行本次正式发行的 CapsLockFlyout-Setup.exe，选择安装位置。
安装器提供“使用 Windows 服务开机自启”“添加到开始菜单”两个独立选项。
安装包包含 x64 .NET 运行时；需要 Windows 11 x64，22000 或更高。

升级前从托盘退出旧程序，将新版安装到原目录。避免同时运行两版。
若使用完整运行包而不是安装器，不能只复制 EXE，需要保留所有配套文件。

程序自身运行数据与日志保存在安装目录 Data 子目录。
Windows 仍需管理服务登记、卸载记录、可选开始菜单快捷方式及安装临时文件；不承诺系统盘零写入。
卸载会删除 Data，若需要保留其中日志，请事先备份。

## 托盘与自启

普通双击 EXE 打开设置。关闭设置窗口后程序继续在托盘运行。
双击托盘图标可再次打开设置；右键提供设置、显示预览与退出。
服务自启选项的修改需要管理员授权。服务负责在用户登录等会话事件后启动托盘程序，界面仍运行在用户桌面中。

常用命令：

- CapsLockFlyout.exe --startup：启动托盘程序，不打开设置。
- CapsLockFlyout.exe --preview：显示预览浮窗。
- CapsLockFlyout.exe --exit：退出正在运行的实例。

## 配合 G-Helper

本程序会将 G-Helper 已有配置中的 disable_osd 设为 1，避免重复提示。
首次运行后建议重启 G-Helper，使它读取该设置。
本程序读取其现有配置和日志，不代替 G-Helper 控制硬件。
G-Helper 自身的数据位置不由本程序迁移。

## 诊断与反馈

输入法诊断默认关闭。排查时可先退出程序，再使用 --startup --ime-diagnostics 启动；
显示状态会记录到安装目录 Data/ime-diagnostics.jsonl，不记录输入文本。
用普通方式重新启动即可停止这项诊断日志。分享日志前仍应检查隐私。
