# CapsLockFlyout 1.1.3

Windows 11 x64 中文状态浮窗。1.1 在原有大写锁定与 G-Helper 状态提示上，增加输入法与模式显示。

## 新增功能

1.1.3 支持按应用身份禁用商店/MSIX 应用的输入法浮窗。

- “选择已安装应用…”可以直接搜索并选择“照片”等商店/MSIX 应用，按包族标识与具体应用 ID 禁用，不依赖版本化路径，常规更新后无需重新添加。
- 旧 EXE 名单继续有效；“转换所选”只转换经当前安装清单验证的唯一路径，并在确认后保存。无法识别的旧路径保留，可改为重新选择已安装应用。
- 第一次保存旧格式名单时，在 Data 中生成 ime-exclusions.json.v1-backup；回退 1.1.2 前需退出程序并恢复此旧格式备份。备份不含后续新增规则。

保留功能：

- 设置 → 输入法浮窗禁用程序 → 添加 EXE…，可多选 EXE；所选程序处于前台时停止输入法提示，切入时收起旧的语言浮窗，离开后不补弹。其他浮窗不受影响。
- 名单按完整 EXE 路径匹配，立即保存到安装目录 Data/ime-exclusions.json，重启后保留；程序更换安装路径后需重新添加。

资源管理器可添加 `C:\Windows\explorer.exe`（Windows 非默认安装位置时改为对应路径）。桌面和任务栏通常也属于该进程，会一同受此规则影响。

原有功能：

- 汉语：中文模式 / 英语模式。
- 英语：直接输入。
- 日语：平假名 / 片假名 / 直接输入。
- 固定浮窗宽度，语言名与模式名分区显示、分别过渡；模式名居中。
- 每 120 ms 查询前台应用的实际状态，不以键盘按键预测。
- 启动与解锁后先静默读取基线，仅在状态变化时提示。
- 切换前台窗口后静默 400 ms，持续同步状态但不弹提示，结束后不补弹；同一窗口内的后续切换正常提示。静默期内的主动切换也可能被抑制。

## 本地运行

此目录是完整运行包，包含 x64 .NET 运行时。先从托盘退出旧版，再运行本目录的 CapsLockFlyout.exe；必须保留旁边的 DLL 等文件，不能单独复制 EXE。

普通双击打开设置；关闭设置窗口后继续在托盘运行。右键托盘可设置、预览或退出。更改服务自启需要管理员授权。

安装版可选择安装位置、自启与开始菜单快捷方式。发行文件以 GitHub Releases 为准，本地运行包不等于已发布的安装版。

程序自身日志位于可执行文件旁 Data 目录；默认不启用输入法诊断，不记录输入文本。Windows 系统登记等不属于程序自身日志。

## 注意

- 输入法与大写锁定功能无需 G-Helper 或 Windhawk。
- Win+Space 选择面板的高亮项尚未提交时，等待系统实际状态改变后才显示；不预测中间选项。
- 状态不变的 Shift / Caps Lock 不弹语言提示。日语输入法下抑制大写锁定浮窗。
- 日语全角与半角片假名共用显示名。
- 第三方输入法或部分应用可能返回未知或滞后状态；本机验证不代表全应用兼容。
- 系统音量、亮度仍由 Windows 自身显示。
- 首次配合 G-Helper 使用后建议重启它，避免旧 OSD 重复显示。
